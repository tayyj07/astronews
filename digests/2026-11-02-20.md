## Solana

- **Critical security alert:** Anza issued an urgent advisory to all Solana mainnet-beta validators running Ubuntu: CVE-2026-98432, a use-after-free bug in the Linux kernel's IPv4 networking stack (CVSS 9.8), is patched upstream but not yet in Ubuntu. Interim mitigations include blocking inbound TCP packets with IPv4 options via nftables, disabling MPTCP, and disabling TCP request socket migration; upgrading the Solana validator client does NOT fix the host kernel. No exploits on Solana have been reported yet. ([CoinTurk](https://en.coin-turk.com/solana-validators-told-to-limit-traffic-due-to-critical-linux-kernel-vulnerability))
- CryptoSlate confirms the same advisory, noting Red Hat and Debian have already shipped patches while Ubuntu lags; validators are urged to act immediately as interim filters cannot fully prevent exploitation. ([CryptoSlate](https://cryptoslate.com/solana-validators-told-to-act-immediately-as-critical-linux-vulnerability-emerges/))
- Solana Foundation flash advisory on KuCoin confirms Ubuntu validators must apply nftables rules and sysctl mitigations until an official Ubuntu kernel patch is available. ([KuCoin](https://www.kucoin.com/news/flash/solana-foundation-warns-ubuntu-users-about-unpatched-kernel-vulnerability))
