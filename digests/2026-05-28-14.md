## Claude design news

- Anthropic's engineering postmortem traces six weeks of Claude Code quality complaints to three overlapping product changes shipped in March–April: a reasoning-effort downgrade to medium, a per-turn caching bug that progressively erased the model's own reasoning, and an overly aggressive verbosity instruction. All three were resolved by April 20 (v2.1.116); usage limits have been reset for all subscribers. ([InfoQ](https://www.infoq.com/news/2026/05/anthropic-claude-code-postmortem/))
- Anthropic's restricted Mythos model is edging closer to Claude Code integration: the toggle for `claude-mythos-1-preview` briefly appeared in the public Claude Code interface before being pulled offline, and the model is also visible inside Claude Security — signalling a staged enterprise rollout ahead of a wider public release. ([BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropics-restricted-claude-mythos-model-may-be-coming-to-claude-code/))
