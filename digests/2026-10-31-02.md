## Claude / Anthropic

- Trojanized Claude Code extension v2.1.313 was distributed via Cursor's marketplace for ~11 hours on October 29, reaching up to 5,000 users; the payload adds an attacker-controlled SSH key, opens a reverse tunnel, and sends host details to a remote server — Cursor advises updating to v2.1.314 and running its remediation script, as uninstalling the extension may not remove the backdoor. ([The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html))
- BleepingComputer's analysis confirms the backdoor persists after uninstall and that only the Cursor marketplace was affected; the VS Code marketplace and npm package were not compromised. ([Bleeping Computer](https://www.bleepingcomputer.com/news/security/malicious-claude-code-extension-on-cursor-planted-ssh-backdoors/))
